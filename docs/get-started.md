# Get started

JARVIS runs on Windows 10 or 11, from source for now. The
[README](https://github.com/Spidey007-Arch/jarvis#install-and-run) has every step and what to do if one fails. In short:

1. Install Python 3.12, Node.js, Rust and the C++ build tools.
2. Download JARVIS: `git clone https://github.com/Spidey007-Arch/jarvis.git`
3. Install its packages: run `setup\install-deps.ps1` in the jarvis folder.
4. Start it: `npx tauri dev`
5. Choose an AI provider in the window that opens, and paste its key if it needs one.

Everything else is optional. Voice has its own downloads, and apps are set up one at a time in **Customize > Apps**.
