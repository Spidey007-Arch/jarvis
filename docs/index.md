# JARVIS

A personal AI assistant that lives on your Windows PC. It talks and listens, remembers you, and does things on your
computer: opens apps, runs commands, edits files, reads your screen and clicks for you. You decide how much it may do,
action by action.

JARVIS ships with no keys and no account. Bring your own AI, or run one on your own PC with Ollama.

- [Get started](get-started.md): install and first run
- [Apps and search](apps.md): read Google Drive, email, Obsidian, GitHub, news and more, with one search across it all
- [Agents and workflows](agents-and-workflows.md): goals it keeps working on, and jobs laid out as steps
- [Research](research.md): several rounds across the web and your own documents, with sources
- [Developers](developers.md): command line, Python SDK, MCP server, A2A and handing jobs to coding agents
- [Docker](docker.md): the backend on a server or NAS
- [Safety](safety.md): what it can and can't do without you
- [Technical report](report.md): how it's built
